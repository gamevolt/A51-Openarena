# ShellScripts

Various utility scripts, mainly targeting a FreeBSD system.

**NOTE:** They may have additional dependencies, not found in a standard installation.
To solve that, one might find installing 'pkg-provides' useful for
finding any missing software package.

PKG_SEARCH
: Explore available, pre-compiled packages.

rbible
: Display a random Bible verse (KJV'1850 revision).

ROTATE_SCREEN.sh
: Rotates the display in the specified direction. Directions may also be defined by using symbolic links with pre-defined names.
